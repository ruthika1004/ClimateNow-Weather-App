# ClimateNow Weather App 🌥️🌩️🌧️
ClimateNow is a simple and responsive weather application built using HTML, CSS, and JavaScript.

## Features
- Search weather by city
- Displays temperature
- Shows humidity and wind speed
- Weather condition icons
- Responsive user interface
- Uses Fetch API and async/await

## Technologies Used
- HTML
- CSS
- JavaScript
- WeatherAPI


# 🌤 ClimateNow Weather App

ClimateNow is a responsive and user-friendly weather application built using **HTML, CSS, and JavaScript**.  
The app fetches real-time weather information using **WeatherAPI** and displays weather details for any searched city.

🔗 **Live Demo:**  
https://your-live-link-here

---

## ✨ Features

✅ Search weather by city name  
✅ Displays real-time temperature  
✅ Shows weather condition dynamically  
✅ Humidity information  
✅ Wind speed details  
✅ Dynamic weather icons  
✅ Responsive and modern UI  
✅ Fetch API integration  
✅ Uses async/await for API handling  
✅ Error handling for invalid city names

- CSS3
- JavaScript (ES6)
- WeatherAPI
